## 고친 제품 결함 11건

### 요청 경계에서 (T021·T026)

| 결함 | 근거 |
|---|---|
| Step 검증 실패 메시지가 **사용자 입력을 통째로 되돌려 보냈다** — `fill` Step 이면 그 자리가 비밀번호다 | EC-005·SC-209 |
| 공백뿐인 이름으로 프로젝트가 **만들어졌다** — `min_length=1` 은 `"   "` 를 통과시킨다 | AP-010 |
| 녹화 중이 아닌데 **중지가 성공했다** | AP-020 |
| 없는 주소·허용되지 않은 방법이 **계약 밖 응답**을 냈다 — 화면의 오류 추출기가 읽지 못한다 | EC-008·RG-104 |

### 외부 경계에서 (T022·T024·T028)

| 결함 | 근거 |
|---|---|
| Step 실패에 **분류가 없었다** — "대상 사이트가 응답하지 않은 것"과 "제품이 깨진 것"을 받는 쪽이 문구로 짐작해야 했다 | AP-033 |
| 대상 사이트 무응답이 **요소 탐색 실패처럼** 보였다 — 사용자를 없는 문제로 보낸다 | AP-031 |
| AI 실패가 **200 응답에 문장으로만** 실렸다 — 분류도 다음 행동도 없다 | AP-032·AP-033 |
| 테스트 정의·비밀 저장소가 **곧바로 덮어써졌다** — 쓰기가 끊기면 반쪽 파일이 원본 자리에 남는다 | AP-042 |
| 파일 쓰기 실패가 `INTERNAL_ERROR`(broken)로 나갔다 — 공간·권한을 고치면 되는데 "할 수 있는 일이 없다"로 읽힌다 | AP-042 |

### 화면에서 (T025·T027)

| 결함 | 근거 |
|---|---|
| 상태 위반 거부가 **"안 된다"만 말했다** — 지금 무엇이 가능한지 알려주지 않아 사용자가 되는 것을 하나씩 눌러 찾아야 했다 | AP-020 |
| 프로젝트 「만들기」가 **이유 없이 눌리지 않았다** — 무엇이 빠졌는지 화면에 없었다 | AP-003 |
| **AI 실패 사유가 화면에서 사라졌다** — 실패한 세션이 검토를 위해 `paused` 로 옮겨가면 그 사유를 그리는 유일한 화면을 떠난다. 001 의 같은 결함을 002 가 고쳤으나 구멍이 `paused` 로 옮겨졌을 뿐이었다 | AP-032·DR-020 |

## 늘어난 오류 코드 4종

`data-model.md §1.2` 는 기존 23개 + `INTERNAL_ERROR` 를 적었다. 판정 결과 **분류할 자리가
없는 실패가 넷** 드러나 코드를 더했다. 모두 `blocked` 이며, 전수 대응표 검사가 누락을 막는다.

| 코드 | 분류 | 왜 필요했나 |
|---|---|---|
| `STEP_FAILED` | `blocked` | Step 을 수행하지 못한 것. 정의를 고치거나 대상을 다시 집으면 된다 |
| `TARGET_UNREACHABLE` | `blocked` | 대상 사이트 쪽 사정. **제품 결함으로 보이게 해서는 안 된다** (AP-031) |
| `AI_FAILED` | `blocked` | 다시 시도하거나 직접 이어받을 수 있다 (AP-032) |
| `STORAGE_WRITE_FAILED` | `blocked` | 공간·권한을 확인하면 된다. `SESSION_LOST` 를 `blocked` 로 둔 것과 같은 판단 |

## 바로잡은 시나리오 정의 8건

실패가 제품 결함이면 제품을 고치고, **시나리오 정의가 틀린 것이면 목록을 고친다.** 근거는
목록의 `note` 에 남겼다.

| 시나리오 | 무엇이 틀렸나 |
|---|---|
| AS-005 | 테스트 이름 유일성 규칙이 없다 — 판정 대상은 "기존 것이 덮어써지지 않는가" |
| AS-034·AS-035 | AI 작성 경로는 실패를 거부가 아니라 결과로 알린다 (FR-081) |
| AS-044 | 저장은 멱등이다 — 판정 대상은 "테스트가 하나 더 만들어지지 않는가" |
| AS-010 | 화면에 **암호구 확인란이 없다.** 같은 자리의 실재하는 규칙(8자 이상)으로 바꿨다 |
| AS-012 | 화면에 **후보를 지우는 조작이 없다.** 후보는 기록 시점에 수집되고 표시만 된다 |
| AS-037 | "응답하지 않는 동안" 을 밖에서 만들 수 없다 — 제품에 지연 스위치를 넣는 것은 헌법 원칙 II 가 금지한다 |
| AS-047 | 제품 화면에 **주소가 없어** 두 번째 창을 같은 세션 화면으로 데려갈 수 없다 |

## 이 라운드가 만든 검증 계층

| 계층 | 무엇을 보는가 |
|---|---|
| `test_error_contract.py` | 모든 오류 코드가 분류·다음 행동을 갖는가. 처리되지 않은 오류가 정상 거부와 코드만으로 갈리는가 |
| `test_route_sweep.py` | 등록된 **모든** 요청 경로가 규약을 지키는가. 새 경로는 선언 없이 통과하지 못한다 |

| `test_no_failure_injection.py` | 이 라운드의 실패 대역이 **검증 코드에만** 있는가 (헌법 원칙 II) |
