# 계약 — 디자인 대조 (008 판)

**대상**: `scripts/design_baseline.py` · `scripts/design_render.py` · `docs/design/008-visual-language/conformance/*.md`
**요구사항**: FR-281 ~ FR-284 · SC-401
**대체 관계**: 002 의 `contracts/design-conformance.md`(DC-001~DC-012)를 **잇는다.** DC 요구사항은
유지하고, **판정 축만 바꾼다.**

---

## §1 — 왜 축을 바꾸는가

002 가 세운 축은 확정 디자인에서 뽑은 **텍스트 통계**였다 — `div 141개` · `svg 23개` ·
`#1A7F45 5회` · `border 1px 23회`.

이 축은 세 가지를 **원리적으로** 잡지 못한다 (spec V-10).

| 못 잡는 것 | 왜 |
|---|---|
| 행 결말 마커가 빠졌다 (V-05) | `div` 개수가 같으면 통과한다 |
| 필터·정렬이 없다 (V-07) | 없는 요소는 세어지지 않는다 |
| 격자가 grid → flex 로 바뀌었다 (V-08) | 텍스트 카운트에 격자 개념이 없다 |

그리고 이 축은 **사람이 채워야 한다.** 화면당 26칸 × 18장 = 509칸이고, 같은 구조를 001·002 가
두 번 시도해 두 번 다 미완으로 남았다 (`001 T156` · `002 T099`, SC-108 은 지금도 미충족).

> **절차가 완료되지 않는다면 그 절차가 결함이다.** 세 번째로 같은 형태를 만들지 않는다.

## §2 — 3층 축

| 층 | 무엇을 대조하나 | 판정 주체 | 실패하면 |
|---|---|---|---|
| **L1 값** | 정본 시트 ↔ 확정 디자인 시트 | 기계 | 검사 실패 |
| **L2 소비** | 화면 코드 ↔ 정본 | 기계 | 검사 실패 |
| **L3 구조·가감** | 화면 ↔ 확정 디자인 | 사람 | 대조표에 `불일치` |

### 논증

```
L1 이 참:  정본 == 확정 디자인      (렌더 계산값 비교)
L2 가 참:  화면 == 정본만 소비      (가드)
────────────────────────────────────────
따라서:    화면의 색·기하·타이포 == 확정 디자인   (구성상, 사람 판정 불필요)

남는 것:   L3 — 무엇이 거기 있는가, 상태를 어떻게 말하는가
```

**L1 이나 L2 중 하나라도 없으면 이 논증이 무너지고 509칸으로 돌아간다.**

## §3 — L1: 값 대조 (기계)

**도구**: `scripts/design_render.py` — chromium 으로 두 쪽을 **같은 방식으로 렌더**해
`getComputedStyle` 을 읽는다.

| | 렌더 대상 |
|---|---|
| 기준 | `docs/design/008-visual-language/Language.dc.html` (시각 언어 정의 화면) |
| 관측 | `frontend/src/theme/tokens.css` 를 적용한 동일 마크업 |

렌더 가능함은 실측 확인됐다 (research R2 — `support.js` 404 는 렌더에 영향 없음).

### 재는 항목

형태 27종 각각에 대해:

| 속성 | 예 |
|---|---|
| `height` | `.btn` 32px · `.chip` 19px · `.srow` 52px |
| `border-radius` | `.btn` 3px · `.chip` 2px |
| `border-width` · `border-color` | `.pane` 1px `#E3E6EB` |
| `background-color` | `.chip.pass` `#E8F5ED` |
| `color` | `.lbl` `#6E757F` |
| `font-family` · `font-size` · `font-weight` · `letter-spacing` | `.lbl` mono 11 600 .08em |
| `box-shadow` | `.btn` `0 1px 2px rgba(20,23,28,.07)` |

**계산값을 비교하므로 표기 차이에 걸리지 않는다** — `#FFF` 와 `#ffffff` 와 `rgb(255,255,255)` 는
같은 값으로 판정된다. 텍스트 대조가 못 하던 일이다.

## §5 — L3: 구조·가감 대조 (사람)

**화면당 정확히 3항목.** 넘으면 기계로 옮길 수 있는지 먼저 검토한다 (FR-282).

| # | 항목 | 묻는 것 | `불일치` 의 예 |
|---|---|---|---|
| L3-1 | **가감** | 확정 디자인에 있는 요소가 전부 화면에 있는가. 없는 것을 더하지 않았는가 | 목록 필터 칩 4종이 없다 (V-07) |
| L3-2 | **구조** | 영역 분할·순서·계층이 확정 디자인과 같은가 | 표 머리와 행이 같은 격자를 공유하지 않는다 (V-08) |
| L3-3 | **상태** | 각 상태가 확정 디자인의 표현으로 구분되는가. **색만으로 구분하지 않는가** | 통과와 미실행이 시각적으로 같다 (V-05) |

### 판정 방법

```bash
# 1. 확정 디자인을 연다 (브라우저에서 그대로 열린다 — research R2)
open docs/design/008-visual-language/<Screen>.dc.html

# 2. 제품의 같은 화면을 띄운다
# 3. L3-1 · L3-2 · L3-3 을 하나씩 본다
```

### 판정 주체

**구현자가 자기 구현을 판정하지 않는다.** 002 가 세운 규칙이며 유지한다 — 자기 확인은 대조가
아니다. 판정자는 구현자 외의 사람이다.

> **이 규칙이 완료를 막는 것이 001·002 의 실패 형태였다.** 그래서 항목을 화면당 3개로 줄였다.
> 54항목은 한 자리에서 끝낼 수 있는 양이다. 그럼에도 판정이 남으면 **그 사실을 완료 보고에
> 명시한다** — 조용히 넘어가는 것이 같은 일을 세 번 만든 방식이다.

## §6 — 대조표의 형식

`scripts/design_baseline.py --write` 가 화면당 1장을 생성한다.

```markdown
# 디자인 대조 — <Screen>

**기준**: docs/design/008-visual-language/<Screen>.dc.html
**대상**: frontend/src/<파일>
**요구사항**: DC-002 ~ DC-007 · 완료 판정 SC-401

## L1 값 — 기계가 채운다
| 형태 | 속성 | 기준값(렌더) | 관측값(렌더) | 판정 |

## L2 소비 — 기계가 채운다
| 항목 | 기준값 | 관측값 | 판정 |

## L3 구조·가감 — 사람이 채운다
| # | 항목 | 묻는 것 | 판정 | 비고 |
```

**불변식**

- **DC-A** L1·L2 칸을 사람이 손으로 적을 수 없다. 검사가 채운다
- **DC-B** L3 는 화면당 3항목을 넘지 않는다
- **DC-C** 완료 조건은 `불일치` 0건 **그리고** `미판정` 0건 (SC-401)
- **DC-D** 확정 디자인 파일이 바뀌면 기준값 추출이 먼저 멈춘다. 기준과 코드가 따로 움직일 수
  없다 (FR-280 — 현행 `assert_baseline` 동작 유지)

## §7 — 002 의 DC 요구사항과의 대응

| DC | 002 의 뜻 | 008 에서 어느 층이 맡는가 |
|---|---|---|
| DC-001 | 디자인에 없는 값을 만들지 않는다 | L1 (가드 G-4) |
| DC-002 | 구조 — 영역 분할·순서·계층 | **L3-2** |
| DC-003 | 컴포넌트 — 종류·개수·배치 순서 | **L3-1** |
| DC-004 | 치수 | L1 (렌더 계산값) |
| DC-005 | 타이포·색 | L1 (렌더 계산값) |
| DC-006 | 상태의 시각 표현 | **L3-3** |
| DC-007 | 가감 — 더하지도 빼지도 않는다 | **L3-1** |
| DC-009 | 미정의 상태 기록 | 별도 문서 (`undefined-states.md`) |
| DC-012 | 대조 기록을 남긴다 | 이 계약 전체 |

**DC 요구사항은 하나도 버리지 않았다.** 넷(DC-001·004·005 과 소비 축)이 사람에게서 기계로
옮겨졌을 뿐이다.
