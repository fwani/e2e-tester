`StepInspector`
**대체하지 않는 것**: `TestList` · `CreateTest` — 한 테스트의 국면이 아니다 (FR-217a)

## 4. 옮기지 않음 — 이유 필수

| 기존 artboard | 영역 | 판정 | 이유 |
|---|---|---|---|
| AiRecord | Step 행의 초록/보라 **체크 표식** | **옮기지 않음** | 그것은 결말 표시가 아니라 **작성 주체** 표시였고, 작성 주체는 Step 패널 헤더의 배지가 이미 담당한다 (FR-228). 결말을 모르는 국면에서 통과 체크를 그리면 통과처럼 보인다 (S-09 · FR-225). 대신 「기록됨」 중립 표식을 둔다 — 승인 대상 A2 |
| Main · RunnerPaused · Takeover · AiRecord | 미러 흰 영역 **안쪽**의 표본 화면 (`flex: 0 0 170px` 사이드바 · 목록 행 · 버튼 등) | **옮기지 않음** | **우리 UI 가 아니다.** 확정 디자인의 흰 영역은 대상 앱의 미러이며 그 안의 표본은 데이터다. 우리가 그리면 안 된다 (002 가 이미 같은 판단을 했다) |
| RunResult | `TRACE` 탭 | **옮기지 않음 (형태는 유지)** | 서버가 501 을 준다(001 의 알려진 차이). 확정 디자인에 있는 것을 빼지 않으려고 그리되 비활성 + 이유로 둔다 (DC-007 · FR-246) |

**개수 차이는 그 자체로 불일치가 아니다.** 002 §4 가 이미 같은 주의를 적었다 — 확정
디자인은 표본 데이터가 든 정적 목업이므로 개수는 표본의 양에 따라 달라진다. 위 표의
용도는 **§1~§4 가 다루지 않은 영역이 있는지** 사람이 훑을 때의 눈금이다.

`<svg>` 가 77 → 34 로 줄어든 것은 §4 의 둘째 항목 때문이다. 미러 흰 영역 안쪽의 표본
화면(대상 앱의 아이콘들)을 옮기지 않으므로 그 SVG 는 초안에 없다. **우리 UI 의 SVG 는
전부 옮겼다** — 제품 표시 · 브라우저 툴바 화살표 · 작성 배지 · 결말 표식 · 조작 아이콘.

## 6. 사람이 확인해야 하는 것

이 표는 **구현자가 작성했다.** 002 §4 의 규칙대로 판정은 사람 몫이다.

- §1 의 `그대로` 9건 — 값이 실제로 기존 artboard 의 것인지
- §2 의 `이동` 8건 — 옮긴 자리가 맞는지, 특히 A3·A4, 그리고 **RunnerPaused 조작 블록이
  좌측 보조 영역이 아니라 Step 패널 바닥으로 간 것**(converge T092 가 초안과 구현의
  차이를 찾아 고친 자리다)
- §3 의 `분리` 3건 — 540 → 460 + 좌측이 맞는지
- §4 의 `옮기지 않음` 3건 — **이유가 성립하는지.** 여기가 요소를 잃는 지점이다

승인 절차는 `docs/PENDING-HUMAN-VERIFICATION.md` §6 이 갖는다.

| AI 사용 불가 안내 (`#FFF9D6` · `role="status"` · DR-021) | ③-b 안, 방법이 AI 일 때 | **그대로** | 눌러 봐야 아는 것은 늦다는 판단이 그대로다 |
| 「돌아가기」/취소 버튼 | 국면 띠의 `nav.back` | **이동** | 여덟 국면에서 같은 자리다 |
| 카드의 `minHeight: 232px` · `boxShadow: 6px 6px 0` | 카드 높이 자동 · 선택 시 `5px 5px 0` | **이동(치수)** | 승인 대상 B7. 232px 는 1000px 셸의 2열 격자 값이고, 작업 영역에서는 내용 높이가 정한다. 그림자는 확정 디자인의 강조 버튼 값(5px)과 맞췄다 |

## 2-4. `AiCompose.tsx` — 확정 디자인이 없던 화면

`AiCompose` 는 **확정 디자인에 대응 artboard 가 없었다.** 1회차가
`design-conformance/undefined-states.md` 에 그 사실을 기록해 두었고, 2회차에 그 화면이
만들기 국면으로 흡수되면서 항목이 **해소**된다 (아래 T124 의 기록).

| `AiCompose` 의 영역 | 새 위치 | 판정 |
|---|---|---|
| 「자연어 지시」 라벨 + textarea(8행) + placeholder 3줄 | ③-b 의 지시문 자리 (6행) · `data-action="ai.compose"` | **이동** — 행 수만 줄었다 (작업 영역 높이) |
| 「지시문은 테스트로 저장되지 않습니다」 (001 FR-064) | 같은 자리 아래 | **그대로** |
| 「AI 실행 →」 버튼 | 국면 띠의 `ai.start` (「AI 시작」) | **이동** — 라벨이 `wording.ts` 하나로 모였다 (ui-contract §5) |
| `disabled={busy \|\| instruction.trim() === ""}` | 권한표 조건 **C14** | **이동** — 화면이 하던 판정을 표로 옮겼다 (FR-233) |
| 74px 띠의 「AI로 테스트 만들기」 + 시작 URL 표시 | 국면 띠의 국면 알약 + 진행 표시 | **이동** |
| `StatusPill` 「지시문 작성」 | 국면 알약 「만들기」 | **이동** — 국면 표시는 화면에 하나뿐이다 (FR-219) |

## 2-5. 사람이 확인해야 하는 것 (2회차)

이 표도 **구현자가 작성했다.** 판정은 사람 몫이다 (002 §4).

- §2-3 의 **`옮기지 않음` 1건** — 카드의 46px 아이콘 사각형. **여기가 요소를 잃는
  지점이다.** 확정 디자인에서 요소를 뺀 유일한 항목이며 DC-007 위반 여부를 사람이 정한다
- §2-3 의 `분리` 2건 — 카드와 시작 버튼의 자리를 가른 것이 맞는지
- §2-2 의 `옮기지 않음` 2건 — B5(기대 위치 표시)·B9(녹화 안내 띠) 철회가 성립하는지
- 승인 대상 **B1~B10** — `contracts/ui-contract.md` §1-4
- **`CreateTest.dc.html` 을 대체하는 것 자체** — 확정 디자인을 초안으로 대체하는 결정이다
