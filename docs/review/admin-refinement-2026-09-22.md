# 가벼운 admin 구성으로 조정

사용자 피드백: 굵은 글씨와 많은 버튼 때문에 시선이 분산된다.

- 내비게이션과 프로젝트 진입 화면을 밝은 중립색으로 바꿨다.
- 제목 600, 목록 강조 500, 일반 버튼·배지 400으로 굵기를 구분했다.
- 목록 행의 결과/실행 조작은 테두리를 없애고, 결과 필터는 밑줄로 선택을 표시한다.
- 번호 정리·엑셀 내보내기·가져오기는 `목록 관리`로 묶었다.
- 보조 Step 조작은 `Step 편집 도구`로 묶고 패널 위쪽에서 바로 펼칠 수 있게 했다.
- Step 행 조작은 hover·키보드 초점·선택 시 보이고, hover가 없는 기기에서는 항상 보인다.
- 기존 API와 확인 절차는 유지했다. 내보내기 테스트에 접기/펼치기 동작을 추가했으며, 실제 화면 순회에도 열린 목록 관리 상태를 추가했다.

열린 목록 관리 팝업이 도구 줄 밖으로 펼쳐지는 것은 의도된 동작이다. 이 상태에서만 해당 조상의 세로 넘침을 허용하며, 메뉴의 잘림과 조작 덮임 검사는 유지한다.

검증: 프로덕션 빌드 통과(기존 번들 크기 경고 유지), 122개 파일/1,469개 테스트 통과. 20개 화면 상태 × 4개 창 크기 = 80개 조합 모두 도달했고 등록되지 않은 검출은 0건이다. 허용 36건은 기존 404/의도적 연결 끊김 28건과 열린 관리 팝업의 의도된 세로 확장 8건이다.
