## 화면 깨짐 실측

### 절차

1. **격리 인스턴스** — 임시 `XDG_DATA_HOME`·`XDG_CONFIG_HOME` 에 제품 서버를 띄운다. 사용자의
   실제 프로젝트를 읽지도 쓰지도 않는다.
2. **시드** — 프로젝트 1개(그룹 2: `LOGIN`·긴 이름의 `CART`), 테스트 6개(17 Step 1개, 200자에
   가까운 이름 1개, 미실행 3개), 초안 1개.
3. **실제 결과** — 픽스처 앱(`fixtures/sample-app`, 4300)을 상대로 재실행 세션을 API 로 돌려
   `TC-001`·`LOGIN-001` 통과, `TC-003` 실패 결과를 만든다. 결과 파일을 손으로 짓지 않는다.
4. **순회** — 빌드한 화면을 chromium(headless)으로 열고 뷰포트 **1280×800 · 1440×900 ·
   1920×1080 · 2560×1440** 에서 화면마다 캡처하고 DOM 을 잰다.
5. **판정** — 각 요소에 대해
   - **덮임**: 조작 요소의 보이는 중심점에서 `elementFromPoint` 가 그 요소·자손·조상·연결된
     라벨이 아니면 덮인 것이다. 스크롤 컨테이너 밖으로 밀려난 요소는 제외한다.
   - **넘침**: `overflow: visible` 인데 `scrollWidth > clientWidth`.
   - **잘림**: `overflow: hidden` 이고 말줄임이 없는데 `scrollWidth > clientWidth`.
   - **줄바꿈**: 버튼·링크의 글자 조각 사각형이 서로 다른 줄에 있다.
   - **창 밖**: 고정 위치가 아닌 요소가 뷰포트 좌우 밖에 있고 조상이 자르지 않는다.
   - **콘솔**: 오류 메시지와 4xx·5xx 응답.
6. **사람 대조** — 검출기의 오탐을 캡처로 걸러낸다 (아래).
