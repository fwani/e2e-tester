## 1. 그룹 접두어 (변경)

| 항목 | 지금 | 이후 |
|---|---|---|
| 패턴 | `^[A-Z][A-Z0-9]{0,7}$` | `^[A-Z][A-Z0-9]*(?:-[A-Z][A-Z0-9]*)*$` |
| 길이 | 정규식 안에 (최대 8) | 정규식 밖 `max_length=12` |
| 예약어 | `TC` | `TC` (그대로) |

**길이를 정규식에서 뺀 이유**는 R1 — Pydantic v2 의 `pattern` 이 Rust regex 로 컴파일되어
선읽기를 쓸 수 없고, 마디 구조와 전체 길이를 한 정규식에 함께 담으려면 선읽기가 필요하다.
`max_length` 로 나누면 JSON Schema 의 `maxLength` 로 실려 화면까지 같은 값이 내려간다.

**소속은 여전히 저장하지 않는다.** 식별자의 접두어가 곧 소속이라는 013 의 결정
(`project.schema.json` 의 `TestGroup` 설명)은 바뀌지 않는다. 이번 변경은 그 접두어가
가질 수 있는 **모양**만 넓힌다.

## 2. 테스트 식별자 (읽는 방법 변경)

꼴은 그대로 `<접두어>-<번호 3자리>`다. **경계가 마지막 하이픈**이 된다.

| 식별자 | 접두어 | 번호 |
|---|---|---|
| `TC-014` | `TC` | 14 |
| `USER-001` | `USER` | 1 |
| `IT-PM-001` | `IT-PM` | 1 |

## 3. 읽기 함수 — 새 단일 출처

`backend/src/itb/domain/test_case.py` (또는 그 옆의 전용 모듈)에 둔다. 식별자 패턴이 이미
그곳에 있으므로 읽는 법도 같은 곳에 있어야 갈리지 않는다.

| 함수 | 입력 → 출력 | 대체하는 것 |
|---|---|---|
| `prefix_of(test_id)` | `"IT-PM-001"` → `"IT-PM"` | `split("-", 1)[0]` 12곳 |
| `number_of(test_id)` | `"IT-PM-001"` → `1` | `int(split("-", 1)[1])` 4곳 |
| `test_id_from_filename(name)` | `"IT-PM-001-로그인.yaml"` → `"IT-PM-001"` | `groups.py:177` 의 손 복원, `sharing.py:499` 의 파일명 자르기 |

**검증 실패 시 거동**: 형식에 맞지 않는 값이 오면 조용히 빈 문자열을 돌려주지 않고 예외를
올린다. 지금의 `split` 은 하이픈이 없는 문자열에서 통째로 접두어라고 답해서, 잘못된 값이
집계에 섞여도 드러나지 않았다.

## 4. 파일 이름 정규식 (변경)

```
지금: ^(?P<id>[A-Z][A-Z0-9]{0,7}-(?P<number>\d{3}))-.*\.yaml$
이후: ^(?P<id>[A-Z][A-Z0-9]*(?:-[A-Z][A-Z0-9]*)*?-(?P<number>\d{3}))-.*\.yaml$
```

접두어 부분이 **최소 일치**다 (R4). 파일 이름 규칙 자체(`<식별자>-<이름 slug>.yaml`)는
바뀌지 않는다.

## 5. 생성되는 제약 상수 (신규)

`backend/schema/*.schema.json` 에서 화면이 쓸 제약을 뽑아 생성한다.

- 생성 위치: `frontend/src/types/generated/` 아래 (기존 타입 생성물과 같은 디렉터리)
- 생성 주체: `frontend/scripts/gen-types.mjs` 를 확장
- 담는 것: 그룹 접두어의 `pattern` 문자열과 `maxLength` 수
- 손으로 고치지 않는다. 드리프트는 `uv run python -m itb.schema.export --check` 와 CI 가 잡는다

`TestGroupBar` 가 손으로 적어 둔 정규식을 이것으로 바꾼다.

## 6. 끌기 상태 (화면 안에서만 산다)

서버에 저장되지 않는다. 목록 화면의 지역 상태다.

| 상태 | 값 | 언제 |
|---|---|---|
| 끌고 있는 대상 | 테스트 식별자 목록 | `dragstart` ~ `dragend` |
| 표적 노출 여부 | 참/거짓 | 끌고 있는 대상이 있을 때만 참 (FR-014) |
| 지금 올라와 있는 표적 | 접두어 · `TC` · `새 그룹` 중 하나, 또는 없음 | `dragenter`/`dragleave` |

**끌고 있는 대상을 정하는 규칙** (FR-017): 끈 행이 체크되어 있으면 체크된 전부, 아니면 그
행 하나. 체크 밖의 행을 끌어도 기존 체크는 바뀌지 않는다.
