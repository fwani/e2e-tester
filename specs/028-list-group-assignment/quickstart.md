## 1. 자동 검증

```bash
cd backend && bash scripts/test-backend.sh
cd backend && uv run ruff check src/ tests/
cd backend && uv run lint-imports
cd backend && uv run python -m itb.schema.export --check
cd frontend && npx tsc --noEmit
cd frontend && npx vitest run
```

`uv run pytest` 와 `npm test` 는 쓰지 않는다 — 전자는 시간을 재는 계층을 병렬에 섞어
거짓 실패를 내고, 후자는 감시 모드라 끝나지 않는다.

**기존 실패 기준선을 먼저 확인한다.** 이 저장소에는 028 이전부터 실패하던 항목이 있다.
새로 깨진 것과 원래 깨져 있던 것을 가르지 않으면 판단이 틀린다.

## 2. 손으로 보는 것

### 2-1. 하이픈 접두어 (US1 · SC-001)

1. 테스트 목록 → 「그룹 관리」 → 「+ 그룹」
2. 이름 `프로젝트 관리`, 접두어 `IT-PM` → 만들기
3. **만들어진다.** 「영문 대문자·숫자」 오류가 뜨지 않는다
4. 테스트 하나를 그 그룹으로 옮긴다 → 식별자가 `IT-PM-001` 이 된다
5. 그룹 띠의 건수가 `프로젝트 관리 · 1` 로 센다 (`IT · 1` 이 아니다)
6. 같은 그룹에 하나 더 옮긴다 → `IT-PM-002` (번호가 이어진다)

잘못된 값도 확인한다: `IT-`·`-PM`·`IT--PM`·`IT-001` 은 거부되고 그 자리에서 이유가 읽힌다.

### 2-2. 옛 자산이 그대로다 (FR-011 · SC-002)

028 이전에 만든 프로젝트를 연다.

- 목록·그룹 건수·재실행·엑셀 내보내기가 전과 같다
- `USER-001` 같은 옛 식별자가 `USER` 그룹으로 세어진다
- 변환하라는 안내가 뜨지 않는다 (마이그레이션이 없다)

### 2-3. 끌어 놓기 (US2)

1. 그룹이 둘 있는 목록에서 **끌기 전** 화면을 본다 → 표적 띠가 없다 (SC-005)
2. 행 하나를 끈다 → 표적 띠가 나타난다
3. 표적 위에 올린다 → 어디에 놓이는지 구분된다
4. 놓는다 → 옮겨지고, 무엇이 어느 그룹으로 갔는지 알린다
5. 셋을 체크하고 그중 하나를 끈다 → 셋이 함께 간다
6. 체크 밖의 행을 끈다 → 그 행만 가고 체크는 그대로다
7. 표적 밖에 놓는다 → 아무것도 바뀌지 않고 띠가 사라진다
8. 목록을 스크롤하며 끈다 → 표적에 닿는다
9. 이미 그 그룹인 것을 같은 그룹에 놓는다 → 번호가 다시 매겨지지 않는다

### 2-4. 그룹이 없을 때 (US3 · SC-004)

그룹이 0개인 프로젝트에서:

1. 테스트를 체크한다 → **선택 띠에 새 그룹을 만들어 옮기는 길이 보인다** (지금은 아무것도 없다)
2. 행을 끈다 → 「새 그룹으로」 표적이 나타난다
3. 놓고 이름·접두어를 넣어 확인한다 → 그룹이 생기고 테스트가 그 안에 들어간다
4. 같은 흐름을 취소한다 → 그룹도 안 생기고 테스트도 안 움직인다

이 과정에서 목록 화면을 떠나지 않는다.

### 2-5. 포인터 없이 (US4 · SC-006)

마우스를 쓰지 않고 키보드만으로:

- 테스트를 체크하고 「그룹으로 옮기기」로 같은 이동을 끝낼 수 있다
- 새 그룹 만들어 옮기기도 같은 경로로 가능하다

### 2-6. 왕복 (SC-007)

`IT-PM` 그룹이 있는 프로젝트에서:

1. 엑셀로 내보낸다 → 다시 들여온다 → 같은 그룹으로 돌아온다
2. 공유 묶음으로 내보낸다 → 다른 프로젝트에서 받는다 → 접두어가 충돌하면 새로 만들어진
   접두어도 규칙을 지킨다

## 3. 무엇을 보면 실패인가

| 증상 | 무엇이 틀렸나 |
|---|---|
| `IT-PM-001` 이 `IT` 그룹으로 세어진다 | 접두어를 앞에서 자르는 자리가 남았다 |
| 그룹 해체가 「없는 테스트」라며 실패한다 | 파일 이름에서 식별자를 복원하는 자리가 남았다 (`groups.py:177`) |
| 화면은 `IT-PM` 을 받는데 서버가 거절한다 (또는 반대) | 규칙이 두 벌이다 — 생성 상수를 쓰지 않았다 |
| 끌지 않았는데 표적 띠가 보인다 | FR-014 위반 — 013 SC-627 이 깨진다 |
| 그룹이 0개인데 체크해도 아무 수단이 없다 | UC-028-04 가 붙지 않았다 |
