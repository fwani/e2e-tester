# Quickstart — 027 을 확인하는 법

**이 증분에서 사용자가 보는 변화는 없다.** 그래서 확인의 무게가 다른 기능과 반대다 —
「새 기능이 되는가」가 아니라 **「아무것도 깨지지 않았는가」**다.

---

## 0. 무엇이 깨졌는지 가장 빨리 아는 법

순서대로 돌린다. **위에서 걸리면 아래를 보지 않아도 된다** — 앞의 것이 더 넓게 잡는다.

```bash
cd frontend && npx tsc --noEmit          # ① 타입 — 능력 묶음이 안 맞으면 여기서
cd frontend && npx vitest run            # ② 화면 검사 전부
cd backend  && bash scripts/test-backend.sh   # ③ 백엔드 (이번 증분은 건드리지 않는다)
```

③ 이 깨지면 **이 증분과 무관한 일이 일어난 것이다.** 027 은 백엔드를 건드리지 않는다.

### 특히 보는 검사

| 검사 | 깨지면 무슨 뜻인가 |
|---|---|
| `CapabilityCoverage` | 조작표에 빈칸이 생겼다 — 이 증분은 표를 건드리지 않아야 한다 |
| `CapabilityUI` | 표가 말한 조작이 화면에서 사라졌다 |
| **(신설) 배선 대조** | **표가 활성이라 말하는 조작이 이어져 있지 않다 — 이 기능이 막으려는 바로 그것** |
| `ScreenSweep` | 화면이 깨졌다 (겉모습이 바뀌면 안 된다) |
| `VisualLanguage`·`ClassExistence` | 정본에 없는 클래스를 썼다 |
| 006·009·011·016·026 화면 검사 | 각 기능의 흐름이 바뀌었다 |

---

## 1. 배선 검사가 실제로 잡는지 본다 (SC-003)

**이 확인이 이 증분의 핵심이다.** 검사가 잡지 못하면 구조를 고쳐도 다시 갈린다.

1. 아무 조작 하나의 능력을 한 화면에서만 **일부러 뺀다.**
2. `npx vitest run` 을 돌린다.

**보여야 하는 것**

- 배선 대조 검사가 **실패한다.**
- 실패 문구가 **어느 조작이 어느 화면에서 빠졌는지** 말한다 (FR-015).
- 읽고 무엇을 하면 되는지 알 수 있다.

**보이면 안 되는 것**

- 통과하는 것. 통과하면 이 증분은 값을 내지 못한다.
- 「어딘가 잘못됐다」로만 끝나는 문구.

3. 뺀 것을 되돌리고 다시 돌려 통과하는지 본다.

---

## 2. 손으로 보는 것 — 세 화면이 그대로인가 (SC-007·SC-008)

```bash
python fixtures/sample-app/serve.py --port 4300
cd backend && uv run itb
cd frontend && npm run dev
```

각 화면에서 **달라진 것이 없어야** 한다.

| 화면 | 확인 |
|---|---|
| 편집 | Step 고르기 · 이름/값 고치기 · 지우기 · 순서 바꾸기 · 저장 · 브라우저 열기 · 충돌 해소 |
| 세션(일시정지) | 같은 편집 조작들 + AI 대화 · 재녹화 띠 · 작업 계획 |
| 결과 | 스크린샷 · 산출물 선택 · 「Step nn 고치기」로 편집 화면 가기 |

**국면 고유의 것이 하나도 사라지지 않아야 한다** (FR-018).

---

## 3. 편집면이 하나가 됐는지 본다 (SC-004·SC-005)

1. 편집 화면에서 Step 하나를 골라 상세를 연다. 고칠 수 있는 항목을 적는다.
2. 세션 화면에서 **같은 Step** 을 골라 상세를 연다.

**보여야 하는 것**

- 고칠 수 있는 항목이 **같다.**
- 클릭 Step 에는 입력값 칸이 없고, 채우기 Step 에는 있다 — **두 화면 모두** 그렇다.
- 민감 참조를 담은 값 칸은 **두 화면 모두** 읽기 전용이다.

3. 같은 값을 두 화면에서 각각 입력하고 저장한 뒤 다시 불러온다 → **결과가 같아야 한다.**

---

## 4. 새 조작을 더해 본다 (SC-001·SC-002)

이 증분이 성공했는지 재는 가장 직접적인 방법이다.

1. 아무 조작이나 하나 더한다 (조작표에서 편집·세션 두 국면에 활성으로).
2. **동작을 한 곳에만 잇는다.**
3. 두 화면에서 눌러 본다.

**보여야 하는 것**: 둘 다 동작한다. 어느 화면에 붙일지 고르지 않았다.

**이것이 026 사고의 재발 시험이다.** 그때는 한 화면에만 붙었고 아무도 알려 주지 않았다.
